# 文渊（WenYuan）博物馆与考古数字化产品家族命名方案

> 本文档为产品命名与项目说明文档，用于统一产品家族命名规范、明确各产品定位，供产品规划、商标申请、市场宣传及项目立项使用。

---

## 一、项目背景与目标

面向博物馆、考古研究所、遗址管理机构及文旅单位，规划一套覆盖**考古发掘记录**与**藏品管理**两大核心业务的数字化产品家族。为解决产品矩阵命名不统一、对外品牌认知分散的问题，特制定本命名方案，确立主品牌与子产品的中英文命名规范，形成可扩展、可注册、可传播的产品家族体系。

**项目目标：**

1. 确立统一主品牌，统摄考古与藏品两条产品线；
2. 制定子产品中英文命名规范，保证家族感与扩展性；
3. 明确各产品定位与模块划分，为后续研发排期提供依据；
4. 为商标注册、域名申请、市场宣传提供命名依据。

## 六、命名规范

1. **中文格式**：统一为 **文渊·X**，中间使用间隔号“·”，形成家族视觉统一。
2. **英文格式**：统一为 **WenYuan X**，空格分隔，模块词使用英文单词而非拼音，便于国际客户理解。
3. **大小写**：WenYuan 首字母大写连写；模块词首字母大写。
4. **备选名使用**：备选名仅在特定场景（遗址平台、库房管理）独立使用，不作为主推产品名。
5. **扩展原则**：新增产品沿用“主品牌 + 单字模块词”结构，中文模块词优先选用单字，英文模块词选用通用专业词。
